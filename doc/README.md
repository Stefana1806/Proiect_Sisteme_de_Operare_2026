##Rolul fiecarui director:
- *doc*: include partea de documentatie 
- *bin*: executabile
- *src*: surse C
- *include*: headere
- *data*: fisiere persistente
- *logs*: loguri
- *reports*: rapoarte, fisierele de output ale cerintelor
- *tmp*: artefacte temporare
- *tests*: scenarii de test 
- *tools*: scripturile care vor fi folosite

##Cum ruleaza auditul: bash tools/t1_audit.sh;
- bash citeste linie cu linie comenzile din *.txt*
- le executa in ordinea in care apar de sus in jos 
- rezultatele sunt salvate in fisierele *.txt* din **reports**
